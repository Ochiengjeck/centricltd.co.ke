# SMS Services (`/sms-services/`)

Source: https://centricltd.co.ke/sms-services/ (fetched 2026-10-16)

## Bulk SMS and PRSP services
Centric Limited's SMS gateway helps businesses send effective text communication to customers when they need it, with SMS APIs supporting two-way chat via shortcode, USSD, and bulk messaging.

Features: custom sender-ID branding (company name instead of a number), website integration, contact-list organization, two-way messaging (recipients can reply), scheduled/automated sending, duplicate-SMS prevention (cost savings), and message personalization with recipient names.

## Short Codes
- **Shared shortcodes** — used by multiple companies at normal mobile-network rates, no extra charges.
- **Dedicated shortcodes** — single-company use, with premium-rate options that generate additional revenue.

Used for: customer service inquiries, promotional campaigns, feedback gathering, service/event registration, banking requests, mobile coupons/discount vouchers, and surveys.

## USSD
- **Dedicated USSD** — a 3-digit code (e.g. `*789#`) for a single company at postpaid rates (free to the customer).
- **Shared USSD** — a multi-company code (e.g. `*789*55#`) with prepaid customer charges.

Capabilities: quick menu creation/customization, 4G LTE compliant with 2G/3G fallback, interactive navigation menus, scalable architecture, and SMS/voice integration.
