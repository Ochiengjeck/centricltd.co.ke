## Backup & Storage
Centric partners with AWS to protect data with strong durability and security via cloud backup — scalable, cost-effective (pay only for what's used), backs up any data type, and built to satisfy security requirements for military/global-bank-grade organizations.

**Fix applied:** the live page claims "99% data durability" for S3/Glacier. Amazon's published figure for S3 Standard/Glacier is **99.999999999% ("11 nines") durability** — corrected here and in the data module.

### Products
- **Amazon S3** — object storage with Standard, Standard-IA, and Glacier storage classes; encryption/access management; scalable; pay-per-class pricing.
- **Amazon S3 Glacier** — low-cost, durable long-term archival with multiple encryption options, data spread across 3+ Availability Zones.
- **AWS Storage Gateway** — integrates on-premise infrastructure with AWS cloud storage.
- **AWS Backup** — automates and centrally manages backups across S3 and Glacier.

Relevant for: Media (durable storage/archival for video/footage), Finance (secure storage and durable archival of sensitive/old data), Government, Communications, Universities, and other data-heavy organizations.

- **Flexible** — scales from 10 to 10,000 users without coding.
- **Embed analytics in apps** — dashboards embed into applications, websites, and portals.

Relevant for: reporting-driven companies (financial markets, real estate, economic reporting via interactive dashboards) and app-integrated enterprises (performance status, banking financial status, live data feeds).

## Amazon WorkSpaces (Desktop as a Service)
Deploy Windows or Linux virtual desktops on demand to any supported device, anywhere — scaling from a handful to thousands of desktops in minutes.

Relevant for: secure cloud desktops for remote/contract staff; secure desktops for software test & development; rapid regional office expansion without hardware investment.

Benefits: reduced desktop/laptop hardware cost; flexible global deployment managed from the AWS console; pay-as-you-go pricing; reduced administrative burden (maintenance/upgrades handled).
